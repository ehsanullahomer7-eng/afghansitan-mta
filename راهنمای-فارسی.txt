افغانستان MTA — نسخه فارسی سایت
================================

۱) فایل ZIP را استخراج کن.
۲) فایل index.html را با Chrome یا Edge باز کن.
۳) برای ویرایش، فایل را با VS Code یا Notepad باز کن.

امکانات:
- طراحی تیره مشکی و آبی با حال‌وهوای گیمینگ
- متن‌های فارسی و راست‌چین
- نشان بیرق افغانستان
- بخش اطلاعات سرور، دانلودها و رتبه‌بندی نمونه
- دکمه ورود نمایشی
- امضای «ساخته شده توسط: احسان الله» و «Prepared by ehsanullah»

تنظیمات:
در انتهای فایل index.html این خط را پیدا کن:
const CONFIG={serverIp:"YOUR_SERVER_IP",serverPort:"22003",communityUrl:"YOUR_DISCORD_INVITE"};

YOUR_SERVER_IP را با آدرس واقعی سرور و YOUR_DISCORD_INVITE را با لینک دعوت دیسکورد جایگزین کن.

توجه:
- این نسخه فقط ظاهر سایت است؛ ورود، ثبت‌نام، پنل مدیریت، آمار زنده و رتبه‌بندی واقعی هنوز پیاده‌سازی نشده‌اند.
- برای سایت آنلاین رایگان می‌توانی از GitHub Pages استفاده کنی.
- برای نمایش عکس‌های پس‌زمینه، مرورگر به اینترنت نیاز دارد.
- فایل‌های بازی را بدون اجازه صاحب حق نشر دوباره منتشر نکن؛ به منابع رسمی لینک بده.
